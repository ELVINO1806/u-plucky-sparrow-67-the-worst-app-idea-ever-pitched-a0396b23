An entry for make.fun's "The Worst App Idea Ever Pitched" bounty. The pitch: MoodRing for Toasters, an app that reads your toaster's emotional state each morning and texts your bread a personalised apology before it burns. `main.py` writes that one-sentence pitch to `/output/entry.txt`.

The entry is exactly one sentence and 145 characters, inside the 240-character limit. The program is deterministic and uses only the Python standard library, so the output is the same on every run.

```bash
python3 main.py
```
